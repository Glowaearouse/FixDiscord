> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*

> Ряд антивирусов относит файлы WinDivert к потенциально опасным или хакерским инструментам, после чего удаляет их и помещает в карантин. Название обнаружения при этом обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky для этого предназначена настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше создать исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите провайдера, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, подойдет `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках опцию "Транзит запросов". При отключенной опции Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Glowaearouse/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Извлеките файлы в путь без кириллицы и специальных символов

5. Запустите требуемый файл
    * Чтобы найти подходящую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для автоматического запуска выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдете работающий у себя вариант**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из служб
  - **`Check Status`** - показать состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения необходимо перезапустить стратегию.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - выбрать режим обработки сервисов из `ipset-all.txt`.  
  Это пригодится при проверке ресурса, который без zapret открывается, а с ним перестает работать.  
  В скобках указано состояние:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - адреса проверяются на наличие в списке
    - `any` - под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** - включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** - заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - заменить `ipset-all.txt` актуальным списком из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - найти распространенные причины неработоспособности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы клиента
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - протестировать сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/Glowaearouse/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и запустите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - В появившемся каталоге откройте файл `hosts` в текстовом редакторе, запущенном от имени администратора
  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение еще раз. Если результата нет, убедитесь, что файл действительно был сохранен.

#### Работоспособность не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Glowaearouse/tg-ws-proxy) или с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем утрачивать работоспособность.**
> Обнаружение определенной стратегии способно произойти не сразу: вариант, который некоторое время работал, позднее может перестать работать.
> В репозитории собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените ее параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок

- Убедитесь, что нужный адрес присутствует в списках доменов или IP-адресов

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Glowaearouse/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Затем выполните `service.bat` -> `Run Diagnostics`; если появятся ошибки, исправьте их и в конце ответьте Y
- Удалите старый каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/Glowaearouse/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Щелкните по архиву правой кнопкой и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК"
- Распакуйте архив в новую папку в корне диска, не используя пробелы, специальные символы и кириллицу
- Запускайте разные скрипты `general` и проверяйте нужные интернет-ресурсы. Если они не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### Не работает игра/приложение с включённым запретом

- Проверьте настройки `service.bat`: `Game Filter` должен иметь значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть ресурсы, которые вы не собирались обходить.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите ее, подставив найденное имя в обе команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, настроен ли [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше доступ работал.
- См. также [#251](https://github.com/Glowaearouse/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, с которой открывается сайт YouTube, и запустить ее
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, используйте ее
- Если браузерная версия также недоступна, повторите проверку всех стратегий. YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Glowaearouse/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Glowaearouse/tg-ws-proxy)
- Либо подключитесь к бесплатному MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не сработает, дополнительно активируйте `ipset any`

Учтите: режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включенным постоянно. Сначала выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/Glowaearouse/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите ее [здесь](https://github.com/Glowaearouse/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Добавлять адреса для обхода можно в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
